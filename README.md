## O que você encontra aqui

| Pasta | Para quê | Resultado |
| --- | --- | --- |
| [`perfil/`](perfil) | README do seu perfil no GitHub | Uma página de apresentação com stack, contatos e estatísticas |
| [`repositorio/`](repositorio) | README dos seus projetos | Descrição, instalação, uso, contribuição e licença |
| [`badges-shields/`](badges-shields/readme.md) | Selos de tecnologias, redes sociais e ferramentas | Badges prontos, com a URL para copiar |
| [`cards-status/`](cards-status/readme.md) | Estatísticas do seu GitHub | Cards com temas para escolher |
| [`avancado/`](avancado/readme.md) | Recursos do Markdown do GitHub | Alertas, seções recolhidas, diagramas e mapas |

## Como usar

1. Escolha um modelo e abra o arquivo `.md`.
2. Copie o conteúdo e cole no seu `README.md`.
3. Troque `{seu nome}`, `SEU-USUARIO` e `iuricode` pelos seus dados.

> [!TIP]
> Para o README de perfil, crie um repositório **público** com o mesmo nome do seu usuário do GitHub e coloque o `README.md` nele. O GitHub mostra esse arquivo no topo do seu perfil.

## Modelos de repositório

O [Exemplo 01](repositorio/exemplo-01.md) é um README completo para projetos: badges, descrição, lista de tarefas, pré-requisitos, instalação, uso, como contribuir, colaboradores e licença.

## Estrutura

```text
readme-template/
├── perfil/            # modelos de README de perfil
├── repositorio/       # modelo de README de projeto
├── badges-shields/    # catálogo de badges
├── cards-status/      # cards de estatísticas e temas
├── avancado/          # alertas, diagramas, mapas e mais
├── CONTRIBUTING.md    # como contribuir
└── LICENSE.md         # licença MIT
```
